# mapTree

Локальный сайт генеалогического древа: показывает **всех** людей по поколениям
(вверху старшие, внизу младшие), включая повторные браки и детей от них.

## Установка (Windows, PowerShell)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser          # логин для редактора
python manage.py import_gedcom tests\rootsmagic_tree.ged --root @I1@
python manage.py runserver
```

Древо: http://127.0.0.1:8000/ · Редактор: http://127.0.0.1:8000/admin/

`--root` — от кого считать поколения (он = 1). Повторный импорт: добавить `--replace`
(удалит всё, что было в базе!).

## На странице древа

Перетаскивание — двигать, колесо — масштаб, клик по карточке — сведения о человеке.
Клавиши: `+` `−` масштаб, `0` всё древо, `Esc` закрыть карточку. Поиск понимает и
латиницу, и кириллицу («seko» найдёт «Секо»). Ссылка вида `/#P0002` открывает человека.
«SVG для печати» скачивает всё древо одним векторным файлом.

## Как добавить ребёнка от второго брака

Редактор → «Семьи» → открыть нужную пару (или создать новую) → в блоке
«Дети этой семьи» добавить строку. Даты вводятся как `10.08.1962`, `1962`,
`около 1850`, `до 1790`, `1850-1860`.

## Правила удаления

Удалить можно только человека без детей и только если после удаления никто
не окажется оторванным от древа. Удаление требует двух подтверждений.

## Устройство

| Папка | Что внутри |
|---|---|
| `tree_engine/` | Ядро без Django: модель, GEDCOM, поколения, раскладка, SVG |
| `genealogy/models.py` | Люди, семьи, события и факты, варианты имени, места, источники с файлами |
| `genealogy/bridge.py` | База данных → ядро → координаты для браузера |
| `genealogy/views.py` | Страница, API `/api/tree/`, `/api/people/<id>/`, `/tree.svg` |
| `genealogy/admin.py` | Временный редактор (позже — свои формы прямо на древе) |
| `static/genealogy/` | Отрисовка, перемещение, поиск, панель человека |
