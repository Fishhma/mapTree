# Ядро генеалогического древа (tree_engine)

Чистый Python 3.10+, без внешних зависимостей. Django-часть будет строиться поверх.

| Модуль | Что делает |
|---|---|
| `model.py` | Люди, семьи (союзы), события с «нечёткими» датами; правила удаления |
| `gedcom.py` | Импорт GEDCOM 5.5/5.5.1 (RootsMagic, FamilySearch и др.) |
| `generations.py` | Поколения от опорного человека (он = 1, родители = 2 …) |
| `layout.py` | Раскладка всего древа по поколениям, линии браков и детей |
| `render_svg.py` | SVG для предпросмотра и печати |

## Запуск

```powershell
python preview.py tests\rootsmagic_tree.ged tree.svg @I1@
python -m unittest -v
```

`@I1@` — ID опорного человека в GEDCOM. Файл `.ged` с данными живых людей
в публичный репозиторий не коммитить (он в `.gitignore`); тесты без него
частично пропускаются.
